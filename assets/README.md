# Kaferry visuals

Adapted from the supplied Claude designs. Navy `#0E2A47`, orange `#E8662E`, teal `#1B8A8F`; reversed artwork uses light `#F2F5F7` and cyan `#4FC1C6`.

| Asset | Use |
| --- | --- |
| `kaferry-logo.svg`, `kaferry-logo-dark.svg` | Primary wordmark, cropped for the README; light and dark versions. |
| `kaferry-mark.svg`, `kaferry-mark-dark.svg` | Standalone ferry on light or dark backgrounds. |
| `kaferry-mark-mono.svg` | One-color reproduction. |
| `kaferry-mark-small.svg` | 16-pixel mark; omits waves for legibility. |
| `kaferry-icon.svg` | Rounded navy icon tile. |
| `kaferry-social-preview.svg` | Editable master for the social card. |
| `kaferry-social-preview.png` | GitHub upload: 1280×640, below 1 MB. |

Lettering is outlined from [Space Grotesk](https://github.com/floriankarsten/space-grotesk) 700 and [IBM Plex Mono](https://github.com/IBM/plex) 400. SVGs need no installed fonts, scripts or network requests. To change lettering, use those fonts in a vector editor and outline it again before export.

The social example includes the required `GROUP` and an explicit `START`.

Set the repository's image under **Settings → General → Social preview → Edit → Upload an image**, using the PNG. Committing it alone does not change that setting. [GitHub instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
