Use the same statement and configuration as run, with a named GROUP.
Use status --json to read the verdict and saved progress as JSON.
Run kaferry status --help for the command's flags.

Verdict                   Exit  Meaning
unknown                      5  Saved progress is absent, invalid or
                                incompatible, or the group has an incompatible
                                active member.
running                      6  Kafka group activity, unsettled state or a
                                membership change was observed.
incomplete                   4  Part of the selection has no saved stop.
limit_reached                7  All selected partitions have saved stops and at
                                least one stopped at a worker record cap.
complete_within_staleness    0  Source processing finished under the configured
                                timestamp assumptions.
complete                     0  Source processing finished for the selected
                                finite scope: saved offset ends or the
                                saved archive selection.
