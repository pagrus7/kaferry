# Kaferry v0.4.0

Preview copies with `explain` and run the CLI without a native Kafka library.

## Changes

- `kaferry explain` shows endpoints, time windows, saved progress and starting positions as text or JSON. It does not join a group, commit, create files or take locks.
- The CLI uses franz-go and builds without a C compiler or native Kafka runtime.
- SQL errors identify the offending location without echoing SQL or credentials.
- `--version`, an MIT license and security reporting guidance are included.

## Upgrade

- Review connection properties: only the documented subset is accepted; unsupported properties fail at startup.
- Stop workers before upgrading. Existing Kafka progress, file checkpoints and CBOR archives remain compatible.
- A bounded Kafka worker that receives no partitions exits `3`; rerun it with the same query and group to pick up unfinished work.

## Known issues

- franz-go v1.22.2 misreads Kafka record timestamps outside ±9,223,372,036,854 Unix milliseconds.
