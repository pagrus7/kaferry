# Kaferry v0.1.0

Initial release: copy full Kafka records between topics and CBOR files using SQL-like statements. For current downloads, use the [latest release](https://github.com/pagrus7/kaferry/releases/latest).

## Changes

- Topic→topic, topic→file, file→topic and file→file copying; raw keys, values, nulls, ordered headers and timestamps where possible.
- Record-time filters, consumer-group progress and at-least-once delivery.
- CBOR archive format v1.

## Known issues

A [librdkafka bug](https://github.com/confluentinc/librdkafka/pull/5397) can crash Kafka-source startup during coordinator failures, before copying or saving progress. This version uses Confluent Go/native client 2.15.0 and has no mitigation. Rerun after coordinator recovery. Production frequency is unknown. Native commit and close have no hard overall shutdown deadline.

See the [client limits and permissions for this version](https://github.com/pagrus7/kaferry/blob/v0.1.0/design/client-compatibility.md).

## Downloads

Linux AMD64/ARM64 and macOS ARM64 archives, `SHA256SUMS` for the archives and Go build information. See the [build and run instructions for this version](https://github.com/pagrus7/kaferry/blob/v0.1.0/README.md#build-and-run).
