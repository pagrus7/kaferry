# Kaferry v0.5.0

Capture and restore compressed Avro archives with rotation, recovery and resumable replay.

## Changes

- `FILE avro('directory')` preserves full records and their original cluster, topic, partition and offset in Snappy-compressed files.
- Capture workers can write independently to local or shared storage. Files rotate by compressed size or age; interrupted captures recover saved data before continuing.
- Replay saves a fixed selection of completed files and resumes from group checkpoints. `explain` and `status` support Avro archives.
- `WORKER_STOP_AFTER_RECORDS` stops each process after accepting the requested number of writes. Each restart gets a fresh allowance; saved status distinguishes this stop from reaching the end of the input.

## Upgrade

- Stop workers before upgrading. Kafka commit metadata and single-file checkpoints have new formats; v0.4.0 saved progress is rejected. Use a new `GROUP` and, for single-file output, a new path. Rolling back also requires fresh progress and a new single-file output path.
- Existing single-file archives remain readable. File-to-file copies require matching formats.
- Avro replay includes only files completed when its group first starts. Use a new group to include files captured later. [Archive usage](https://github.com/pagrus7/kaferry/blob/v0.5.0/docs/usage.md#run-a-copy) · [Storage requirements](https://github.com/pagrus7/kaferry/blob/v0.5.0/design/archive.md#layout-and-ownership).

## Known issues

- franz-go v1.22.2 misreads Kafka record timestamps outside ±9,223,372,036,854 Unix milliseconds. [Scope and Kafka 4+ defaults](https://github.com/pagrus7/kaferry/blob/v0.5.0/design/client-compatibility.md#known-issues).

## Downloads

Linux AMD64/ARM64 static binaries and macOS AMD64/ARM64 binaries. Archives include `LICENSE` and `THIRD_PARTY_NOTICES.txt`. Each platform also has Go build information, an SPDX SBOM, and provenance and SBOM attestation bundles; `SHA256SUMS` covers all files.

Verify archive provenance with `gh attestation verify ARCHIVE --repo pagrus7/kaferry`. Verify the extracted binary's SBOM with `gh attestation verify kaferry --repo pagrus7/kaferry --predicate-type https://spdx.dev/Document/v2.3`.
