# Security

Security fixes target the latest release. Use the latest version; older releases do not receive separate fixes.

Report suspected vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/pagrus7/kaferry/security/advisories/new), including dependency vulnerabilities affecting Kaferry. Use [public issues](https://github.com/pagrus7/kaferry/issues) for ordinary bugs.

Include `kaferry --version`, your platform, impact and steps to reproduce. Remove credentials and private record data from SQL, configuration and logs. Do not post vulnerabilities or secrets in public issues.

Reports and fixes are handled on a best-effort basis; there is no guaranteed response time.
