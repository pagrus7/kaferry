# Kaferry v0.10.0

Restore at-least-once copying and the original Kafka permissions.

## Changes

- Remove exactly-once delivery because it introduced unanticipated complexity and Kafka permission requirements outside the tool's intent.
- Copies use at-least-once delivery: acknowledged output may repeat after a crash or reassignment. Kafka producers retain idempotent retries. [Delivery contract](https://github.com/pagrus7/kaferry/blob/v0.10.0/design/decisions.md#delivery-and-progress).
- Kafka copies no longer require a progress topic or transactional-ID permissions. Source-group offsets and archive replay checkpoints determine resume positions. [Permissions](https://github.com/pagrus7/kaferry/blob/v0.10.0/docs/usage.md#permissions).

## Upgrade

- Remove `worker.progress_topic` from existing configuration; `run --recover-local` is no longer available.
- Stop workers before replacing binaries. Saved state from v0.9.0 is unsupported; no migration is provided. Start independent copies with new groups and fresh checkpoint and capture directories. These copies can repeat output already present at the destination.
- Completed Avro archive files remain readable. Existing transactional Kafka output still requires `read_committed` readers to exclude aborted records.

## Known issues

- franz-go v1.22.2 misreads Kafka record timestamps outside roughly 1677–2262. [Exact bounds and Kafka timestamp defaults](https://github.com/pagrus7/kaferry/blob/v0.10.0/design/client-compatibility.md#kafka-input-timestamps).
- AWS IAM signing and credential rotation are covered by component tests; release tests do not contact MSK.

## Downloads

Linux AMD64/ARM64 static binaries and macOS AMD64/ARM64 binaries. Archives include `LICENSE` and `THIRD_PARTY_NOTICES.txt`. Assets include the archive tutorial bundle, `qualification.md`, per-platform Go build information, SPDX SBOMs, provenance and SBOM attestation bundles, and `SHA256SUMS`.

Linux container images are published as `ghcr.io/pagrus7/kaferry:v0.10.0`. Source installation requires Go 1.26+: `CGO_ENABLED=0 go install github.com/pagrus7/kaferry/cmd/kaferry@v0.10.0`.
