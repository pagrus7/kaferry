# Kaferry v0.8.0

Connect to more Kafka authentication setups and copy inclusive offset and partition ranges.

## Changes

- Kafka connections support OAuth bearer tokens, AWS MSK IAM and Kerberos, alongside PLAIN and SCRAM. OAuth supports client credentials or an externally refreshed token file. [Connection settings](https://github.com/pagrus7/kaferry/blob/v0.8.0/docs/reference.md#connection-properties).
- `RECORD_OFFSET BETWEEN lo AND hi` and `PARTITION [NOT] BETWEEN lo AND hi` include both endpoints. Equivalent offset comparisons and partition lists retain the same saved query identity.
- First-use Kafka groups are accepted when no saved progress exists. Group inspection retries temporary coordinator errors within the request deadline.
- The Docker image includes a persistent, broker-free archive tutorial. The usage guide adds a local Kafka playground and task-based examples for copying, stopping, resuming and checking results.
- Container publishing maintains `ghcr.io/pagrus7/kaferry:latest` for the current stable release.

## Upgrade

- Existing v0.7.0 queries and saved progress remain compatible. Stop workers before replacing their binaries. The new authentication settings and `BETWEEN` syntax require v0.8.0.

## Known issues

- franz-go v1.22.2 misreads Kafka record timestamps outside roughly 1677–2262. [Exact bounds and Kafka timestamp defaults](https://github.com/pagrus7/kaferry/blob/v0.8.0/design/client-compatibility.md#kafka-input-timestamps).
- AWS IAM signing and credential rotation are covered by component tests; release tests do not contact MSK.

## Downloads

Linux AMD64/ARM64 static binaries and macOS AMD64/ARM64 binaries. Archives include `LICENSE` and `THIRD_PARTY_NOTICES.txt`. Assets include the archive tutorial bundle, `qualification.md`, per-platform Go build information, SPDX SBOMs, provenance and SBOM attestation bundles, and `SHA256SUMS`.

Linux container images are published as `ghcr.io/pagrus7/kaferry:v0.8.0`. Source installation requires Go 1.26+: `CGO_ENABLED=0 go install github.com/pagrus7/kaferry/cmd/kaferry@v0.8.0`.
