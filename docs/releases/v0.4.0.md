# Kaferry v0.4.0

Preview and inspect copies, export metrics, and run without a native Kafka library.

## Changes

- Optional OpenTelemetry metrics export through OTLP/HTTP, plus progress logs every 30 seconds; both are configurable.
- `kaferry explain` summarizes endpoints, resume/start rules, time windows and record-error policies; JSON includes every partition. It does not join a group, commit, create files or take locks.
- `kaferry status` reports saved per-partition stops and observed group activity without consuming or writing.
- The CLI uses franz-go and builds without a C compiler or native Kafka runtime. Shutdown exits `1` at `worker.shutdown_timeout` (default 30 seconds); unsaved work may replay.
- SQL errors identify the offending location without echoing SQL or credentials.
- `--version`, an MIT license and security reporting guidance are included.
- Fix bounded-copy edge cases, self-copy exit codes and archive resume diagnostics.

## Upgrade

- Review [connection properties](https://github.com/pagrus7/kaferry/blob/v0.4.0/design/decisions.md#connection-properties): only the documented subset is accepted; unsupported properties fail at startup.
- Stop workers before upgrading. Kafka commit metadata and file checkpoints have new formats; older saved progress is rejected. Start with a new group and, for file output, a new path. Rolling back also requires a new group/output. Single-file archives remain compatible.
- A bounded Kafka worker that receives no partitions exits `3`; rerun it with the same query and group to pick up unfinished work.

## Known issues

- franz-go v1.22.2 misreads Kafka record timestamps outside ±9,223,372,036,854 Unix milliseconds. [Scope and Kafka 4+ defaults](https://github.com/pagrus7/kaferry/blob/v0.4.0/design/client-compatibility.md#known-issues).

## Downloads

Linux AMD64/ARM64 static binaries and macOS AMD64/ARM64 binaries. Archives include `LICENSE` and `THIRD_PARTY_NOTICES.txt`. Each platform also has Go build information, an SPDX SBOM, and provenance and SBOM attestation bundles; `SHA256SUMS` covers all files.

Verify archive provenance with `gh attestation verify ARCHIVE --repo pagrus7/kaferry`. Verify the extracted binary's SBOM with `gh attestation verify kaferry --repo pagrus7/kaferry --predicate-type https://spdx.dev/Document/v2.3`.
