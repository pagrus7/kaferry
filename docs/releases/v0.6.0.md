# Kaferry v0.6.0

Select source partitions, preserve Kafka partition placement, and install Kaferry from source or containers.

## Changes

- Kafka destinations preserve original partition numbers by default. Destination `WITH (PARTITIONING = KEY)` selects key-based routing.
- `WHERE PARTITION IN (...)` and `NOT IN (...)` select Kafka source partitions or original partition IDs in Avro archives. Kafka discovers eligible additions while running; Avro retains its saved file selection.
- Source and destination settings use endpoint `WITH` clauses. Omitting `GROUP` starts a fresh one-off copy; Kafka input without timestamp bounds starts at the earliest retained record by default.
- Source installation with `go install` reports the installed module version. Linux AMD64/ARM64 container images package the verified release binaries and license files.
- Release builds use Go 1.27.3; Go dependencies and analysis, vulnerability, SBOM and CI tools are updated. Broker fixtures use Kafka 3.9.2.

## Upgrade

- Stop workers before upgrading. Move `GROUP`, `START` and `CUTOFF` from final `OPTIONS` into source `WITH`; move Avro rotation settings from `avro(...)` into destination `WITH`. Worker stops and error policies remain in final `OPTIONS`. [SQL syntax](https://github.com/pagrus7/kaferry/blob/v0.6.0/design/grammar.md).
- To retain v0.5.0 Kafka output routing, explicitly set destination `PARTITIONING = KEY`. Changing partitioning mode or a partition predicate needs a new group. Keep a named `GROUP` to resume; omitting it starts an independent copy each time.
- CBOR endpoints and single-file checkpoints are no longer supported. Use Avro archive directories; retain v0.5.0 to read existing CBOR archives.

## Known issues

- franz-go v1.22.2 misreads Kafka record timestamps outside ±9,223,372,036,854 Unix milliseconds. [Scope and Kafka 4+ defaults](https://github.com/pagrus7/kaferry/blob/v0.6.0/design/client-compatibility.md#known-issues).

## Downloads

Linux AMD64/ARM64 static binaries and macOS AMD64/ARM64 binaries. Archives include `LICENSE` and `THIRD_PARTY_NOTICES.txt`. Each platform also has Go build information, an SPDX SBOM, and provenance and SBOM attestation bundles; `SHA256SUMS` covers all files.

Linux container images are published as `ghcr.io/pagrus7/kaferry:v0.6.0`. Source installation requires Go 1.26+: `CGO_ENABLED=0 go install github.com/pagrus7/kaferry/cmd/kaferry@v0.6.0`.
